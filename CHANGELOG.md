
# Changelog – The Golden Glaze Bakery

This document records the development changes and improvements made to The Golden Glaze Bakery website.

---

## Part 2 – Initial Website Development

### Added
- Created the homepage with an introduction to the bakery.
- Created the About page with the bakery's background, mission and vision.
- Created the Products page to display cinnamon roll products.
- Created the Enquiry page for customer enquiries.
- Created the Contact page with bakery contact information.
- Added a navigation menu to connect the website pages.
- Developed the website layout using HTML and CSS.
- Applied a consistent bakery-inspired colour scheme and design.

---

## Part 3 – Enhancing Functionality and SEO

### JavaScript Improvements
- Added product search functionality.
- Added product category filtering.
- Added alphabetical product sorting.
- Added a product image lightbox.
- Added JavaScript validation to the enquiry form.
- Added JavaScript validation to the contact form.
- Added feedback messages after form submissions.
- Added DOM manipulation to dynamically update product listings.

### Interactive Features
- Integrated a Leaflet interactive map.
- Added two fictional bakery branch markers for demonstration purposes.
- Added hover effects to interactive elements.
- Added CSS animations and smooth transitions.
- Added reduced-motion support for accessibility.

### SEO Improvements
- Added unique page titles.
- Added meta descriptions to website pages.
- Added relevant meta keywords.
- Improved heading structures.
- Added descriptive image alternative text where applicable.
- Improved internal navigation links.
- Created a robots.txt file.
- Created a sitemap.xml file.

### Documentation
- Updated the README.md file.
- Created this CHANGELOG.md file.
- Documented the website structure and functionality.
